# FCU 氢燃料电池控制器上位机

> WPF (.NET 8.0) 工业控制软件，通过 RS485 接口与氢燃料电池控制器 (FCU) 和电池管理系统 (BMS) 进行通信。

## 功能概览

### FCU 氢燃料电池控制器

| 功能 | 说明 |
|------|------|
| 串口通信管理 | 串口配置、连接管理、自动刷新设备列表 |
| 设备参数读取 | 序列号、电堆信息、配置参数 |
| 参数配置 | 压力、阀门、DCDC、风扇温度、拉载、通用参数 |
| 拉载配方管理 | 5个系统预设 + 用户自建配方 CRUD，支持一键应用到设备 |
| 实时监控 | 电堆工作状态、压力、温度、电压、电流 |
| 系统控制 | 电堆启动/关闭 |
| 功率曲线图 | 实时双曲线（输入/输出功率），10Hz 采样，1000s 时间窗口 |
| 通信帧日志 | 实时显示 TX/RX 完整十六进制帧，支持暂停、自动滚动、清空、复制和保存 |
| 设备地址管理 | 远程修改 FCU 设备地址 (1-247) |
| 自动轮询 | 可配置间隔（0.5s/1s/2s/5s），独立启停 |

### BMS 电池管理系统

| 功能 | 说明 |
|------|------|
| 基本信息监控 | SOC、剩余容量、总电压电流、单体电压、温度（32字节） |
| 电池组配置 | 串并联数、额定容量电压、充放电截止参数 |
| 充放电控制 | 允许/禁止 充电/放电（功能码 0x11） |
| 故障诊断 | 13种故障类型位掩码解析 |
| 主动上报 | 定时上报(0xF3)、报警事件(0xF4)、状态变更(0xF5) |

### 许可证系统

- 90天试用期 + RSA-2048 签名激活
- 硬件指纹绑定（SHA256: CPU + 主板 + MAC + 硬盘序列号）
- AES-256 加密存储，时间回退检测

## 通信协议

```
| 帧头(2) | 地址(1) | 功能码(1) | 长度(1) | 数据域(N) | CRC16(2) |
| AA 55   |         |           |         |           |           |
```

- **字节序**：大端序 (Big-Endian)
- **校验**：CRC16-CCITT
- **设备地址**：FCU 默认 1（可配置 1-247），BMS 固定 2

### FCU 功能码

| 功能码 | 描述 | 响应码 |
|--------|------|--------|
| 0x01 | 读取设备序列号 | 0x81 |
| 0x02 | 设置压力参数 | 0x82 |
| 0x04 | 设置拉载参数 | 0x82 |
| 0x07 | 读取电堆信息 | 0x87 |
| 0x08/0x09 | 启动/关闭电堆 | 0x88/0x89 |
| 0x0A | 读取配置参数 | 0x8A |
| 0x0C | 修改设备地址 | 0x8C |
| 0xF0/0xF1/0xF2 | 报警/状态/拉载上报 | — |

## 系统要求

- Windows 10+ / .NET 8.0 Runtime
- RS485 串口设备

## 构建与运行

```bash
# 构建
dotnet build "FCU 氢燃料电池控.sln"

# 运行
dotnet run --project "FCU 氢燃料电池控/FCU 氢燃料电池控.csproj"

# 发布
dotnet publish "FCU 氢燃料电池控/FCU 氢燃料电池控.csproj" -c Release -o ./publish
```

## 快速使用

1. 连接 RS485 设备到计算机
2. 启动应用，选择串口号和波特率
3. 点击「打开串口」建立连接
4. 使用各 Tab 页进行参数配置和监控
5. 在「通信日志」Tab 查看、复制或保存 RS485 收发帧

## UI 设计

- **主色调**：Material Design 蓝色系 (#1976D2)
- **布局**：左侧固定面板 (270px) + 右侧 Tab 区域 + 底部功率曲线图
- **通信日志Tab**：集中查看 FCU/BMS 的 TX/RX 十六进制完整帧
