# FCU 氢燃料电池控制器上位机

> WPF (.NET 8.0) 工业控制软件，通过 RS485 接口与氢燃料电池控制器 (FCU) 和电池管理系统 (BMS) 进行通信。

## 功能概览

### FCU 氢燃料电池控制器

| 功能 | 说明 |
|------|------|
| 串口通信管理 | 串口配置、连接管理、自动刷新设备列表 |
| 设备参数读取 | 序列号、电堆信息、配置参数 |
| 参数配置 | 压力、阀门、DCDC、风扇温度、拉载、通用参数 |
| 拉载配方管理 | 低电流系统预设 + 用户自建配方，支持一键应用；超出当前50A上限的4个旧预设已下架 |
| 实时监控 | 电堆工作状态、压力、温度、电压、电流 |
| 系统控制 | 电堆启动/关闭 |
| 功率曲线图 | 实时双曲线（输入/输出功率），10Hz 采样，1000s 时间窗口 |
| 通信帧日志 | 实时显示 TX/RX 完整十六进制帧，支持暂停、自动滚动、清空、复制和保存 |
| 设备地址管理 | 远程修改 FCU 设备地址 (1-247) |
| 自动轮询 | 可配置间隔（0.5s/1s/2s/5s），独立启停 |

### BMS 电池管理系统（默认读取FCU缓存，保留直接Modbus诊断）

| 功能 | 说明 |
|------|------|
| FCU缓存监控 | AA55空数据域0x11/18B 0x91；SOC、电压、有符号电流、四状态字与采集年龄；不触发额外BMS采集 |
| 有效性 | 检查在线/SOC标志及6000ms年龄，含主机经过时间；无效实时值显示--，旧状态字标为诊断值 |
| 直接诊断 | 显式勾选并经0x0D接管确认后，保留03H完整寄存器128～152与10H MOS控制 |
| 保护说明 | 直接诊断暂停FCU采集，其SOC门控及BMS保护耦合暂不可用；退出后确认归还轮询 |
| SOC门控提示 | 缓存有效时依据最近回读阈值显示拒启/自动停机；默认60/61，SOC无效明确提示 |
| 总线仲裁 | 默认连接/断开不写0x0D；直接诊断退出按保存的串口/地址归还，提供手动恢复按钮 |

### 控制确认与配方保存

- 状态、报警及启动/关闭应答只作用于当前连接和目标；切换目标前排队的旧回调不会更新新目标。
- 风扇及手动拉载一次只等待一条应答，等待期间暂停普通发送；安全停机和归还BMS轮询仍可用。超时或发送失败后保留3秒迟到应答隔离窗口，结果显示未知，不自动重发。
- 阀门扩展时序0x0202与普通参数共用写入事务；设备确认后回读九项值，一致才显示已保存。启动/关闭的成功应答只表示请求受理，完成状态以电堆状态为准。
- 配方仍使用程序目录的recipes.json；保存失败明确报错并恢复内存，先写同目录临时文件再替换旧文件，避免写入失败截断原配方。用户配方数值不会被自动裁剪。

### 待机采样周期与升级边界

- 系统监控页新增0x0902：1～65535整数秒，默认60秒，仅OFF可写；保存结果后回读一致才提示已保存。旧0x0901仍为0.1秒。
- 当前适配固件main@2c8be1d是0x08000000独立APP，应SWD烧录。升级页只适用于已安装兼容OpenBLT引导的设备及0x08003000配套镜像；不会发送猜测加载命令，也不把缓存0x91当作IAP响应。
- 新报警0x000E解释IWDG/WWDG复位原因；0x000D同时涵盖温度无效与完整采样超时。关机放电低于DCDC门控电压（默认8V）开启，达到或超过关闭；旧2V字段保留，不参与当前放电控制。

### 许可证系统

- 90天试用期 + RSA-2048 签名激活
- 硬件指纹绑定（SHA256: CPU + 主板 + MAC + 硬盘序列号）
- AES-256 加密存储，时间回退检测

## 通信协议

```
| 帧头(2) | 地址(1) | 功能码(1) | 长度(1) | 数据域(N) | CRC16(2) |
| AA 55   |         |           |         |           |           |
```

- **字节序**：大端序 (Big-Endian)
- **校验**：CRC16-CCITT
- **设备地址**：FCU 默认 1（可配置 1-247，0x0C 修改需重启生效）
- **协议版本**：V4.3

### FCU 功能码

| 功能码 | 描述 | 响应码 |
|--------|------|--------|
| 0x01 | 读取设备序列号 | 0x81 |
| 0x02 | 设置压力参数 | 0x82 |
| 0x03 | 设置阀门参数 | 0x82 |
| 0x04 | 设置拉载参数 | 0x82 |
| 0x05 | 设置 DCDC 参数 | 0x82 |
| 0x06 | 设置风扇温度参数 | 0x82 |
| 0x07 | 读取电堆信息 | 0x87 |
| 0x08/0x09 | 启动/关闭电堆 | 0x88/0x89 |
| 0x0A | 读取配置参数 | 0x8A |
| 0x0B | 设置通用参数 | 0x82 |
| 0x0C | 修改设备地址 | 0x8C |
| 0x0D | 设置 BMS 轮询使能（总线仲裁） | 0x8D |
| 0x0E | 设置工作流程参数 | 0x8E |
| 0xF0/0xF1/0xF2 | 报警/状态/拉载上报 | — |

### BMS 通信（Modbus RTU）

BMS **不走 AA55 协议**，上位机作为 Modbus 主站直接通信：

- **从站地址**：默认 1（UI 可配，与固件 `FCU_MODBUS_SLAVE_ADDR` 一致）
- **功能码**：0x03 读保持寄存器（reg128~152）、0x10 写单寄存器（MOS 控制）
- **总线仲裁**：FCU 与上位机都可作 BMS 主站，通过 0x0D 切换；上位机发请求前须满足「AA55 状态机空闲」+「总线静默 ≥20ms」

## 快速使用

1. 连接 RS485 设备到计算机
2. 启动应用，选择串口号和波特率
3. 点击「打开串口」建立连接
4. 使用各 Tab 页进行参数配置和监控
5. 在「通信日志」Tab 查看、复制或保存 RS485 收发帧

> 分支 `fix/upgrade-integrity-audit`（基于 master `13e2ac3`，**待同事审查，未合并**）。
> 输入：同事 BL 部分核查报告三项发现，经逐条对源码复核属实后按 1→2→3 修复。

- **强制全镜像读回校验**（核查问题1，高）：移除 `VERIFY_BY_UPLOAD` 联调开关，固化 (PROGRAM(0)) 后无条件 UPLOAD 全镜像比对（跳过 0x1D8 校验字 4 字节），不一致即中止——不重启、不报成功，设备留 BL 可重升。依据：BL 侧校验字仅覆盖前 7 个向量字（flash.c Two's complement），串口传输无校验字节（CS_TYPE=0），读回比对是整机完整性唯一保障。
- **XCP 应答超时后 SYNCH 同步屏障**（核查问题2，高）：SET_MTA/PROGRAM* 成功应答同为单字节 0xFF 无法区分归属，超时直接重发会让迟到旧应答冒充新命令成功（MTA 未恢复仍报 Ok → 写错地址）。现超时后先 SYNCH 并确认 `[FE 00]`（`IsSynchPositive`：1B 迟到应答长度不符被丢弃无法冒充；非零错误码不算；显式错误=BL 已应答无需屏障），屏障 2 次×200ms 未通过即中止；接入幂等命令与写入块两条重试路径。
- **AA55 应答槽事务过滤 + 地址核对**（核查问题3，中）：新增 `Services/AppFrameWaitSlot`，收帧入口按当前事务（功能码+设备地址）过滤，心跳/主动上报/他机应答不再覆盖已收应答（前置检查不再误判 APP 不在线、0x92 拒绝原因不再退化为泛化超时）；`RequestAppFrame` 补地址核对（应答须与请求同地址，广播除外）。
- 零改动：SrecFile 守卫、XCP 帧格式、升级互斥/退出归一化、0x12/0x92 语义、BMS 缓存与心跳静默。Debug 0 警告 0 错误，离线回归 PASS 434 项（新增 21，含核查报告两个复现场景转绿）。**真机待验证**；本批次豁免三路 Agent 审查，由同事负责审查。
