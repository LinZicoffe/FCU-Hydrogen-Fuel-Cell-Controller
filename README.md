# FCU 氢燃料电池控制器上位机

> WPF (.NET 8.0) 工业控制软件，通过 RS485 接口与氢燃料电池控制器 (FCU) 和电池管理系统 (BMS) 进行通信。

## 功能概览

### FCU 氢燃料电池控制器

| 功能 | 说明 |
|------|------|
| 串口通信管理 | 串口配置、连接管理、自动刷新设备列表 |
| 设备参数读取 | 序列号、电堆信息、配置参数 |
| 参数配置 | 压力、阀门、DCDC、风扇温度、拉载、通用参数 |
| 拉载配方管理 | 5个系统预设 + 用户自建配方 CRUD，支持一键应用到设备 |
| 实时监控 | 电堆工作状态、压力、温度、电压、电流 |
| 系统控制 | 电堆启动/关闭 |
| 功率曲线图 | 实时双曲线（输入/输出功率），10Hz 采样，1000s 时间窗口 |
| 通信帧日志 | 实时显示 TX/RX 完整十六进制帧，支持暂停、自动滚动、清空、复制和保存 |
| 设备地址管理 | 远程修改 FCU 设备地址 (1-247) |
| 自动轮询 | 可配置间隔（0.5s/1s/2s/5s），独立启停 |

### BMS 电池管理系统（Modbus RTU 主站，V1.28-S）

| 功能 | 说明 |
|------|------|
| 基本信息监控 | SOC/SOH、剩余与额定容量、总电压电流、单体电压极值、温度极值（03H 读 reg128~152） |
| 状态位图解码 | reg137 告警 / reg138 保护 / reg139 故障 / reg140 系统状态，48 个位逐位中文解释 |
| 充放电控制 | 充电/放电 MOS 开关（10H 写 reg1/reg2） |
| 拉载阻断提示 | 命中固件关键保护位（0x537F）或 MOS 关断时醒目告警——固件此时会静默拒绝拉载 |
| SOC 门控提示 | 显示固件阈值（>90% 拒启 / >85% 自动停机）并按阈值着色 |
| 总线仲裁 | 0x0D 接管/归还 BMS 总线，含手动「归还FCU轮询」按钮 |
| 离线检测 | 连续 3 次超时判离线，并提示固件侧门控已失效 |

### 许可证系统

- 90天试用期 + RSA-2048 签名激活
- 硬件指纹绑定（SHA256: CPU + 主板 + MAC + 硬盘序列号）
- AES-256 加密存储，时间回退检测

## 通信协议

```
| 帧头(2) | 地址(1) | 功能码(1) | 长度(1) | 数据域(N) | CRC16(2) |
| AA 55   |         |           |         |           |           |
```

- **字节序**：大端序 (Big-Endian)
- **校验**：CRC16-CCITT
- **设备地址**：FCU 默认 1（可配置 1-247，0x0C 修改需重启生效）
- **协议版本**：V4.3

### FCU 功能码

| 功能码 | 描述 | 响应码 |
|--------|------|--------|
| 0x01 | 读取设备序列号 | 0x81 |
| 0x02 | 设置压力参数 | 0x82 |
| 0x03 | 设置阀门参数 | 0x82 |
| 0x04 | 设置拉载参数 | 0x82 |
| 0x05 | 设置 DCDC 参数 | 0x82 |
| 0x06 | 设置风扇温度参数 | 0x82 |
| 0x07 | 读取电堆信息 | 0x87 |
| 0x08/0x09 | 启动/关闭电堆 | 0x88/0x89 |
| 0x0A | 读取配置参数 | 0x8A |
| 0x0B | 设置通用参数 | 0x82 |
| 0x0C | 修改设备地址 | 0x8C |
| 0x0D | 设置 BMS 轮询使能（总线仲裁） | 0x8D |
| 0x0E | 设置工作流程参数 | 0x8E |
| 0xF0/0xF1/0xF2 | 报警/状态/拉载上报 | — |

### BMS 通信（Modbus RTU）

BMS **不走 AA55 协议**，上位机作为 Modbus 主站直接通信：

- **从站地址**：默认 1（UI 可配，与固件 `FCU_MODBUS_SLAVE_ADDR` 一致）
- **功能码**：0x03 读保持寄存器（reg128~152）、0x10 写单寄存器（MOS 控制）
- **总线仲裁**：FCU 与上位机都可作 BMS 主站，通过 0x0D 切换；上位机发请求前须满足「AA55 状态机空闲」+「总线静默 ≥20ms」

dotnet run --project "FCU 氢燃料电池控/FCU 氢燃料电池控.csproj"

## 快速使用

1. 连接 RS485 设备到计算机
2. 启动应用，选择串口号和波特率
3. 点击「打开串口」建立连接
4. 使用各 Tab 页进行参数配置和监控
5. 在「通信日志」Tab 查看、复制或保存 RS485 收发帧

### 2026-09-21（电堆信息轮询无响应修复，feature/openblt-upgrade-adapt）

**真机测试反馈"自动轮询数据不上来，串口工具可见设备流量"**。逐环核验上位机接收链路（串口事件→AA55 状态机→分发→绑定）与固件 0x07/0x87 实现均正确后，定位到三个真实薄弱点并修复（固件依据均已标注在代码注释）：

- **修复问题：连接时 BMS 总线接管（0x0D en=0）单发无确认**——固件自轮询 BMS 的等待窗口（`fcu_modbus.c g_modbus_rx_active`，无 BMS 应答时每 2s 约 200ms）会把窗口内到达的 AA55 字节喂进 Modbus 缓冲（`fcu_protocol.c:486-488`），单发接管指令有概率被吞且整个会话无法恢复（FCU 持续占用总线，其 Modbus 帧在串口工具上常被误认为"设备回复"）。改为 **0x8D 确认 + 3 次重试**（300ms 间隔大于单个吞帧窗口；无 0x8D=指令未被解析=固件未写 Flash，重试无副作用），失败明确告警并提示核对设备地址/断开重连；泵送等待期间用户断开时静默退出，防误报"接管成功"与陈旧指引
- **新增功能：电堆信息轮询健康监测 + 广播探针自动诊断**——固件对 0x07 恒回 0x87，轮询连续 5 次无响应不再是静默无感知：自动发一次广播（0x00）读电堆信息探针（固件 `fcu_protocol.c:527-530` 接受广播地址，0x87 回显地址 0），**有回包=链路正常、设备地址不匹配（提示修改地址）；无回包=链路不通（提示查 485 接线/方向/供电，并说明"每 2 秒的 01 03 00 80 00 19 帧是 FCU 自轮询 BMS 的流量而非回复"）**；本连接内只自动诊断一次防周期性刷屏，断开/停止轮询/关窗三处状态复位

- 修复问题：4 处 UI 默认值与固件不一致（照抄了固件头文件中已过期的注释）——高压最小值 100→**300** KPA、低压下限 35→**30** KPA、低压上限 65→**80** KPA、温度上限 650→**600**（60.0℃）。原值会在用户不先「读取」而直接「写入固化」时下调启动压力门限、抵消固件按需求 5.1 主动下调的风扇全速门限
- 修复问题：电堆/FCU 温度改为有符号解析（`ushort`→`short`，`ResponseParser` 与 `StackInfoData` 同步）。固件允许温度低至 -40℃ 并按二进制补码塞进 `uint16`，原按无符号解析会把 -40.0℃ 显示成 6513.6℃

- 修复问题：0xF1 状态变更上报现在同步刷新主界面电堆状态。该上报是关闭轮询时唯一的实时状态通道，原实现只写状态栏一行文字，主状态框会一直停留在上次 0x87 的旧值；状态码同时翻译为中文（原显示「2 → 3」），提取 `GetStackStateName()` 供 0x87 与 0xF1 共用

- 新增功能：BMS 离线时横幅提示「下位机侧 SOC 门控与 BMS 故障耦合已失效」，这是安全相关的降级状态（固件在 BMS 离线时走宽松策略，电堆可在 SOC 过高或 BMS 保护状态下被启动）

- 优化改进：补齐 5 个功能码的发送前校验（新增 `ParseRequiredField()`，与已有 `TryParseRange()` 配套）——0x03 阀门（五项≥1、周期间隔>打开时长、第二次>第一次）、0x05 DCDC（最低工作电压>放电截至电压）、0x06 风扇温度（占空比 0~100、温度下限<上限）、0x0B 通用（扫描周期≥1）、0x0E 流程（四个 purge 时长≥1）。固件对参数是整帧校验，任一字段非法则整组不生效，原实现只显示笼统的「参数错误」
