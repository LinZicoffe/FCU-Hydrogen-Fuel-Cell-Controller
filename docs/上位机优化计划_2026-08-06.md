### 0.2 固件侧已核实事实（本计划依赖）

- `0x0D set_bms_poll`：数据域 1B（en），响应 0x8D 1B 结果码；**每次都 `fcu_flash_save_params()` 持久化**（`fcu_protocol.c` :1256-1282）。
- 关闭轮询后：`fcu_modbus_poll_task` 直接返回 → 无超时计数 → `s_bms_online` 冻结 → `fcu_control` 按**离线宽松策略**不阻断拉载、不 ABORT（`fcu_modbus.c` :133-135、`fcu_control.c` :75-79）。**即上位机接管期间固件 BMS 保护冻结，安全语义可接受。**
- `0x0E set_flow_params`：数据域 **12B 无参数 ID**：purge_h2_open1(2)/purge_h2_close(2)/purge_h2_open2(2)/purge_drain_hold(2)/drain_mode(1)/low_normal_ref(2)/load_duty(1)；响应 0x8E 1B 结果码。
- `0x0601` 经 0x0A read_config 读取，返回同 12B。
- 电堆信息 0x87 响应仍为 **26B，不含 SOC**——上位机 SOC 只能来自自己读 BMS。
- 校验非零规则：purge 四时长非零、drain_mode∈{0,1}、low_normal_ref≠0、load_duty≤100。

### 0.3 BMS（V1.28-S）已核实寄存器

**03H 读（一次读 reg128~152，25 个寄存器，响应 55B）：**

| 寄存器 | 内容 | 类型/单位 |
|---|---|---|
| 128 | 电流 | S16, 0.01A，充电正放电负 |
| 129 | 电池组电压 | U16, 0.01V |
| 130 | SOC | U16, % |
| 131 | SOH | U16, % |
| 132/133/134 | 剩余/满充/额定容量 | U16, 0.01AH |
| 135 | 循环次数 | U16 |
| 137/138/139 | 告警/保护/故障状态 | U16 Hex，附表 1/2/3 |
| 140 | 系统状态 | U16 Hex，附表 4（BIT1=充电MOS，BIT2=放电MOS）|
| 141 | 功能开关状态 | U16 Hex，附表 5 |
| 145 | 电池组串数 | U16 |
| 146/147 | 单体电压最大/最小 | U16, mV |
| 148 | 电芯温度个数 | U16 |
| 149/150 | 电芯温度最大/最小 | S16, 0.1℃ |
| 151/152 | 功率管/环境温度 | S16, 0.1℃，未监测=0x8000 |

**10H 写（特殊功能寄存器，写 1 个寄存器）：**

| 寄存器 | 功能 | 值 |
|---|---|---|
| 1 | 充电 MOS 控制 | 0xAAAA=开，0x5555=关 |
| 2 | 放电 MOS 控制 | 0xAAAA=开，0x5555=关 |

**异常响应**：`[addr][func|0x80][errcode][CRC Lo][CRC Hi]`，5B；errcode 1=无效功能码/2=无效寄存器/3=无效数据/4=校验错误/5=写入失败。

**CRC**：Modbus CRC16（多项式 0xA001 反向，初值 0xFFFF，**低字节在前**），与 AA55 的 CRC16-CCITT（0x1021 正向，高字节在前）不同，需独立实现。

## 1. 关键决策

- **D1｜仲裁为会话级，禁止逐次握手**：串口连接成功后发 `0x0D en=0`（上位机接管 BMS），断开/退出前发 `0x0D en=1`（恢复固件轮询）。
  - 依据：0x0D 每次写 Flash（页擦写），逐次握手（1 次/秒）≈2 次擦写/秒，约 83 分钟耗尽 1 万次擦写寿命，**绝对禁止**。
  - 残余风险：上位机崩溃未发 1 → 固件轮询永久关闭（已持久化），需现场重连发 1 或重新上电前手动恢复。**记录在 README 注意事项**；固件侧加"仲裁租约超时"为可选后续项，不在本计划。
- **D2｜BMS 模块整体重写为 Modbus RTU 主站**：单次 03H 读 reg128~152（25 reg）；MOS 控制用 10H 写 reg1/reg2；地址 UI 可配，**默认 1**（与固件常量一致，抓包后现场改）。
- **D3｜在线测试整体移除**：UI 区块、6 个按钮 handler、`SendOnlineTestCommand`、常量 `FUNC_ONLINE_TEST/RESP_ONLINE_TEST/ONLINE_TEST_*`、dispatch `case 0x8D` 重映射为 bms_poll 响应。固件从未实现在线测试，该功能本是死代码且撞码。
- **D4｜旧 AA55-BMS 代码全部删除**：3 个轮询定时器→1 个 Modbus 轮询；删除 0x82-32B/0x83/0x87-4B/0x90/0xF3/F4/F5 分支与 `ProcessBMS*`，恢复 0x82/0x87 纯 FCU 分发。
- **D5｜0x0E/0x0601 流程参数**：协议层 + 参数页新增"工作流程参数"组（5 字段 + 读/写按钮）。
- **D6｜报警语义**：0x0008 → "BMS故障"，`AlarmValue` 按附表 3 位解码展示。
- **D7｜Modbus RX 复用同一串口字节流**：字节并行喂给 AA55 状态机（不动）与 Modbus 接收缓冲；仅在请求后超时窗口内按"地址+功能码+CRC"扫描提取响应，FCU 的 AA55 流量自然被 CRC 过滤。
- **D8｜UI 字段映射**（复用现有控件名，不新增显示区）：

| 现有控件 | 新来源 |
|---|---|
| tbk_BMS_SOC / SOH / CycleCount / RatedCapacity / RemainCapacity | reg130 / 131 / 135 / 134 / 132 |
| tbk_BMS_TotalVoltage / TotalCurrent | reg129 (0.01V) / reg128 (S16, 0.01A) |
| tbk_BMS_MaxCellVoltage / MinCellVoltage | reg146 / 147 (mV) |
| tbk_BMS_MaxTemp / MinTemp | reg149 / 150 (0.1℃) |
| tbk_BMS_WorkState / ChargeDischargeState | reg140 附表4 解码 / BIT1+BIT2 |
| tbk_BMS_FaultCode | reg139 Hex + 附表3 解码 |
| tbx_BMS_CurrentFault | reg137/138/139 位解码文本 |
| 电池组串数 tbk_BMS_SeriesCells | reg145 |
| AvgCellVoltage / AvgTemp / 并联数 / Pack额定电压 / 充放电停止电压电流 / 历史故障 | 无对应寄存器（参数区/历史区未确认），显示 "--" |

### h-t1｜Modbus 协议层（新增 `Protocol/ModbusRtu.cs`）
- `ComputeCrc16(byte[], int) -> ushort`：0xA001 反向、初值 0xFFFF。
- `BuildReadHoldingRegs(addr, startReg, count) -> byte[]`（8B 请求）。
- `BuildWriteSingleReg(addr, reg, value) -> byte[]`（10H，**11B 请求**：addr(1)+func(1)+reg(2)+count(2)+bytecount(1)+data(2)+crc(2)）。
- `TryParseResponse(buffer, addr, func, out frame, out consumed)`：滑动扫描；正常帧长度由 func 决定（03H：5+2×count；**10H：8B 回显**=addr(1)+func(1)+regstart(2)+count(2)+crc(2)，不含 bytecount 与数据域）；异常帧 5B（func|0x80）→ 返回 errcode。
- 纯静态、无状态，可单测。

### h-t2｜BMS 数据模型与服务（新增 `Models/BmsData.cs`、`Services/BmsService.cs`）
- `BmsData`：Current(0.01A, S16)、PackVoltage(0.01V)、SOC、SOH、Remain/Full/RatedCapacity(0.01AH)、CycleCount、Alarm/Protect/Fault/SysStatus(Hex)、SeriesCells、CellVoltMax/Min(mV)、CellTempMax/Min(0.1℃, S16)、Online(bool)、LastUpdate。
- `BmsService`：
