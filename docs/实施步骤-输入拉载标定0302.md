# 输入拉载标定0302实施步骤

## 目标与依据
用户要求增加k、b两个拉载参数。依据固件main@9bdddb0的fcu_handle_set_current_calibration、fcu_encode_current_calibration、fcu_protocol_set_current_calibration及协议文档。上位机基线e7813a5，保留上批全部功能。

## 协议约定
- 实测输入电流(A)=k×原始设定电流(A)+b；固件执行(target-b)/k，上位机发送测量曲线系数，不能再次反算。
- 设置0x05，DATA=03 02+k(float32 BE)+b(float32 BE)，10字节；回0x82/1B。k有限正数，b有限，默认1/0。
- 读0x0A，DATA=03 02 00；0x8A DATA=03 02 00+k+b，11字节。0x0301维持6字节设置/4字节参数回读。
- OFF写并保存；0x02非法、0x03忙、0x05长度错、0x09保存失败并回滚。支持读任何运行态。只读到有效回读才更新输入，写ACK成功后再核对单精度数值；超时/断线/不一致不显示保存成功。
