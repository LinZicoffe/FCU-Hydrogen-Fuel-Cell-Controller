## 二、修复自查项（实现方，2026-11-11）

1. 读回校验为强制步骤：失败路径（比对不一致/UPLOAD 失败）均抛 `UpgradeException`，
   位于 PROGRAM_RESET 之前——不重启、不报成功；设备留 BL 可重升。
2. SYNCH 屏障判据 `!Timeout && Data==[FE 00]`：1B 迟到成功应答长度不符被丢弃无法冒充；
   非零错误码 [FE xx] 不算通过；显式错误响应（BL 已应答）不触发屏障直接重试。
3. 屏障覆盖两条超时重试路径（幂等命令 + 写入块）；屏障自身失败 2 次×200ms 后中止。
4. 等待槽过滤器先于发送登记（先清后发序）；所有退出路径 `finally End()`；
   `RequestAppFrame` 补地址核对（广播地址 0 除外）；会话内核验逻辑未动。
5. 零改动面：SrecFile 守卫、XCP 帧格式、互斥/归一化、0x12/0x92 语义、BMS 缓存、心跳静默。
6. 验证：Debug 0 警告 0 错误；离线回归 PASS 434 项（新增 21，含核查报告两个复现场景转绿）。
