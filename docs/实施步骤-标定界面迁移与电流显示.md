# 实施步骤：标定界面迁移与电流显示

## 需求与范围
将现有0x0302输入拉载标定从FCU参数配置移至电流设置，在标定区显示当前输入电流。保留原按钮事件、k/b限制、写后回读、事务互斥及断线清理。协议、固件、版本及安装包均不修改。

## 数据来源
FCU的0x87电堆信息数据域9..10字节为大端U16输入电流，单位0.1A。ResponseParser.ParseStackInfo → HandleStackInfoResponse → Dispatcher → UpdateViewModelStackInfo → MainViewModel.DCDCInputCurrent（÷10，F1）。新显示与系统监控共用此属性，不能采用BMS电流、DCDC输出电流或目标电流。断开串口时用IsConnected隐藏旧数值。

## 步骤A
1. 将grp_CurrentCalibration整体移至电流设置页顶部，仅保留一个实例，保持原有命名和事件。
2. 新增只读输入电流显示及刷新来源说明，复用现有刷新流程。
3. 调整离线页面呈现选择的选项卡；验证实际0x87响应更新读数、0.1A换算、后续刷新以及断开显示。
4. Debug构建、FirmwareAdaptationChecks --ui、实际WPF离线截图检查；更新README和日志后独立审查、具名提交。
5. 三位全新Reviewer分别检查需求完整性、代码架构、风险测试，记录结果后本地收尾提交。

## 验收
电流设置同屏可见电流读数和k/b操作；FCU参数配置无重复标定区；读数随电堆信息更新，未连接显示--；原标定自动检查通过；不发送额外控制指令。真机和高DPI未测边界如实记录。
